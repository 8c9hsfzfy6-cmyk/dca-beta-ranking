# Conditional dependence sensitivity

This completed extension retains three fixed marginal pairs, seven conditional Gaussian copulas, three evaluation sample sizes, and 500 repetitions per setting. The 31,500 paired datasets share 4,500 base random streams across copulas. All 672,000 estimates are archived. No subjects are generated by the audit.

The conditional normal-quantile generator follows Pfeiffer and Gail (2020), Section 4.3, DOI 10.1002/bimj.201800240. It is not a new method. Marginal mixtures and thresholds were fixed before this extension was run; the retained counterexamples remain selected exploratory cases.

From the repository root:
```bash
python run.py verify-correlation
python run.py figures-correlation
```
Optional full reproduction (not part of verification):
```bash
python run.py simulate-correlation
```
The original executed code is preserved byte-for-byte in results/executed_script.py and simulate.py. Its header describes its pre-run preparation status; run_config.json and this README record the completed experiment. The execution record reports Python 3.13.15, NumPy 2.1.3, and SciPy 1.16.3; pandas and matplotlib versions were not recorded, so the environment is not fully locked. These common packages are required; no GPU or network is needed.

The independent audit recomputes all summaries and paired changes from saved estimates. It does not independently reproduce the random subjects, which were not archived. Numerical inverse CDFs have a tested, not globally certified, error below 1e-7. Scientific interpretation and limitations are in Supplement S11. Zero observed errors do not imply zero population error probability. The figure is regenerated from saved summaries, not a new experiment.
